¿Qué es OpenCode?

Vive en la terminal

Una interfaz TUI: entras a tu proyecto, escribes opencode y listo. Para respuestas sin TUI usa opencode run "…"; para el navegador, opencode web y opencode attach.

Cualquier modelo

Anthropic, OpenAI, Google, OpenCode Zen o modelos locales con Ollama. Cada modelo se nombra proveedor/modelo, con los ids de models.dev.

Abierto y extensible

Licencia MIT. Agentes, skills, servidores MCP y plugins se declaran en un solo archivo: opencode.json.

Instalar y arrancar

Script

curl -fsSL https://opencode.ai/install | bash

npm

npm install -g opencode-ai

Homebrew

brew install anomalyco/tap/opencode

Primer arranque

  1. Configura las credenciales de un proveedor: opencode auth login.
  2. Abre la TUI dentro de tu proyecto: cd tu-proyecto && opencode.
  3. Ejecuta /init: genera AGENTS.md con las reglas del proyecto.

Conceptos clave

Agentes
build edita archivos y ejecuta comandos; plan solo lee y propone. Se alternan con Tab. Puedes definir agentes propios en ~/.config/opencode/agents/*.md o en .opencode/agents/, cada uno con su modelo y sus permisos.
Configuración
Todo vive en opencode.json, en la raíz del proyecto o en ~/.config/opencode/. Claves principales: agent, provider, mcp, plugin y share.
Skills
Carpetas con un SKILL.md que el agente carga bajo demanda: .opencode/skills/<nombre>/SKILL.md en el proyecto o ~/.config/opencode/skills/ en global. También lee las de .claude/skills/.
MCP
Servidores de herramientas externas, declarados por nombre en la configuración: 
{
  "mcp": {
    "mi-servidor": {
      "type": "local",
      "command": ["bun", "x", "mi-mcp"],
      "enabled": true
    }
  }
}
Reglas
Un AGENTS.md en la raíz del repo con la estructura, las convenciones y los estándares del proyecto. Se commitea para que todo el equipo comparta las mismas instrucciones.
Compartir
/share publica la sesión en un enlace. Con "share": "manual" en la configuración nada se comparte sin que lo pidas.

Marca cada paso al completarlo. El progreso se guarda en este navegador.

Comandos esenciales

Comando Qué hace
opencodeAbre la TUI en el directorio actual.
opencode run "…"Ejecuta un prompt sin abrir la TUI.
opencode auth loginGuarda las credenciales de un proveedor.
opencode modelsLista los modelos disponibles en formato proveedor/modelo.
/helpMuestra la ayuda.
/initCrea o actualiza AGENTS.md.
/modelsElige el modelo de forma interactiva.
/newEmpieza una sesión nueva (ctrl+x n).
/sessionsLista y cambia de sesión (ctrl+x l).
/undoRevierte el último mensaje y sus cambios en archivos; requiere Git (ctrl+x u).
/compactResume la sesión para liberar contexto (ctrl+x c).
/sharePublica la sesión en un enlace.
/exitSale de OpenCode (ctrl+x q).
TabAlterna entre los agentes build y plan.
ctrl+xTecla líder de todos los atajos.
